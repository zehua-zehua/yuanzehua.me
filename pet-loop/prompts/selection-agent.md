# Selection Agent

Use this prompt when deciding which Loopi candidate should enter staging.

Selection is not based only on the highest score.

The homepage feedback score measures whether Loopi makes visitors more willing to keep learning about Zehua. Treat that as the primary outcome. Positive tags are supporting evidence; risk tags are blockers or variables to reduce.

A candidate can enter staging only if:

- Professional trust does not decrease.
- AI-native feeling does not decrease.
- Continue-learning intent does not decrease.
- Homepage fit and attention balance do not decrease.
- Pet DNA consistency is at least 4/5.
- No red line from `pet-loop/pet-dna.md` is triggered.

If no candidate is safe, keep the current version and write a report explaining why.
